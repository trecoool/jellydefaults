Default library order

Home screen order applied to every new user. "Hide" removes the view from the My Media row.

Off: only users still on the alphabetical default.

Default library sorting

Sort of each library's main tab, applied to every new user. Imported from a user's current sorts (only the ones changed from Jellyfin's default). Web-based clients only (browser, desktop and phone apps), not TV apps.

Off: each library is only set for users still on its default sort.
